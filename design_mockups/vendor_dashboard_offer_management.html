Design principles applied
→ White/light-gray backgrounds only — no colored header blocks
→ Outline SVG icons throughout — no filled/colored icons
→ Status shown as text-color labels — no filled badge backgrounds
→ Large bold title left-aligned, action (+ / Save) right-aligned
→ Form fields grouped in white cards with section labels above
→ Metric cards: label small gray, value large bold, trend ↑↓ colored
→ Action sheet for offer actions (iOS-native pattern)
→ Reactivation: amber left-border info bar + amber card border
