Flow rules
🏪 UNIQUE: skips Banking Model screen — Individual is the default
🏢 CHAIN: shows Banking Model (SHARED or INDIVIDUAL)
💳 CONNECT payout model → Stripe Connect WebView/browser flow
🏦 MOR payout model → manual bank account form
📡 Payout model determined by GET /vendors/{vendorId}/payout-model
🔒 Back navigation disabled throughout entire flow
🗺 Geocoding auto-triggered 1s after address fields complete
🖼 Business image uploaded to server → imageUrl saved in vendor DB
🎛 Business type, food types, certifications: frontend constants (no API call)
📋 Profile completion is now required (not skippable)
